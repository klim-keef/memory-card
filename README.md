# memory-card
Это простая викторина (тренажёр), созданная на языке Python с использованием библиотеки PyQt5. Программа задаёт пользователю вопросы из заранее подготовленного списка и предлагает четыре варианта ответа в виде переключателей.

Как это работает:

При запуске отображается случайный вопрос.
Варианты ответов каждый раз перемешиваются, чтобы правильный вариант не был привязан к одной и той же кнопке.
Пользователь выбирает ответ и нажимает кнопку "Ответить".
Программа проверяет выбор, выводит сообщение "Правильно!" или "Неверно!", подсвечивает верный вариант и показывает текст правильного ответа.
После этого кнопка меняется на "Следующий вопрос", позволяя продолжить тренировку.

Проект поддерживает базовую статистику: подсчитывает общее количество заданных вопросов, число правильных ответов и выводит текущий процент успеха в консоль. Интерфейс состоит из текстовой метки для вопроса, двух панелей (для вариантов ответа и для результата) и управляющей кнопки.
